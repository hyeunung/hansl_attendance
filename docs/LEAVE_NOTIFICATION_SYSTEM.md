# 연차/출장 알림 시스템 전체 로직 및 필터

## 1. 연차/출장 신청 시 알림 (Flutter 앱에서 처리)

### 1-1. SuperAdmin 신청
- **조건**: `userEmail == AppStrings.adminEmail` (정현웅님)
- **알림 대상**: **본인에게만** 확인 알림
- **알림 내용**: 
  - 제목: "✅ {연차/출장} 신청 완료"
  - 내용: "귀하의 {연차/출장} 신청이 접수되었습니다.\n기간: {기간}"

### 1-2. Manager 신청
- **조건**: `AppStrings.managerNames.contains(name)`
- **알림 대상**: **SuperAdmin에게만** 알림
- **알림 내용**:
  - 제목: "👑 Manager {연차/출장} 신청"
  - 내용: "{이름} 매니저님이 {연차/출장}을 신청했습니다.\n기간: {기간}"

### 1-3. 일반직원 신청
- **조건**: 위 두 조건에 해당하지 않음
- **알림 대상**: **SuperAdmin + 해당 부서 Manager만** (Admin 제외)
- **알림 내용**:
  - 제목: "📝 새로운 {연차/출장} 신청"
  - 내용: "{이름}님이 {연차/출장}을 신청했습니다.\n기간: {기간}"

#### 부서별 Manager 매핑:
- **개발1팀, 개발2팀**: 양승진 (개발팀_manager)
- **개발3팀**: 최창열 (개발3팀_manager)  
- **연구소**: 조근일 (연구소_manager)
- **경영지원팀**: 황연순 (경영지원팀_manager)
- **CAD**: 이정화 (CAD_manager)

## 2. 승인/반려 결과 알림

- **알림 대상**: **신청자 개인**
- **알림 내용**:
  - 제목: "✅/❌ {연차/출장} {승인/반려}"
  - 내용: "{신청자}님의 {연차/출장} 신청이 {승인/반려}되었습니다.\n기간: {기간}"

## 3. 알림 전송 방식

### Edge Function 호출
- **함수**: `send_fcm_notification`
- **인증**: Supabase 클라이언트 자동 인증
- **타입**: `admin` (관리자용) 또는 `user` (개인용)

### 알림 대상 결정 로직
- **SuperAdmin/Manager 알림**: `sendNotificationToAdmins()` 사용
- **개인 알림**: `sendNotificationToUser()` 사용
