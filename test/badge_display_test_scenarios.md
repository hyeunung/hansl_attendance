# 승인 관리 화면 배지 표시 테스트 시나리오

## 테스트 목적
각 역할별로 배지 카운트가 실제 표시되는 카드 개수와 일치하는지 검증

## 테스트 시나리오

### 1. superadmin 역할 테스트
**사용자**: superadmin 권한을 가진 사용자
**예상 결과**:
- 4개 탭 모두 표시 (연차/출장, 발주승인, 구매대기, 입고대기)
- 각 탭의 배지 숫자 = 해당 탭에 표시되는 카드 개수

**테스트 항목**:
1. 연차/출장 탭
   - 대기 중인 연차/출장 신청 수 = 배지 숫자
   - 모든 직원의 신청 건 포함
2. 발주승인 탭
   - 승인 대기 중인 발주 요청 수 = 배지 숫자
   - 모든 발주 요청 포함
3. 구매대기 탭
   - 구매 대기 중인 항목 수 = 배지 숫자
   - 모든 구매 대기 항목 포함
4. 입고대기 탭
   - 입고 대기 중인 항목 수 = 배지 숫자
   - 모든 입고 대기 항목 포함

### 2. lead buyer 역할 테스트
**사용자**: lead buyer 권한만 가진 사용자 (superadmin 제외)
**예상 결과**:
- 2개 탭 표시 (구매대기, 입고대기)
- 각 탭의 배지 숫자 = 해당 탭에 표시되는 카드 개수

**테스트 항목**:
1. 구매대기 탭
   - 구매 대기 중인 항목 수 = 배지 숫자
   - 모든 구매 대기 항목 포함
2. 입고대기 탭
   - 입고 대기 중인 항목 수 = 배지 숫자
   - 모든 입고 대기 항목 포함

### 3. 발주 승인 권한자 테스트
**사용자**: middle_manager, final_approver 등 발주 승인 권한만 있는 사용자
**예상 결과**:
- 2개 탭 표시 (발주승인, 입고대기)
- 각 탭의 배지 숫자 = 해당 탭에 표시되는 카드 개수

**테스트 항목**:
1. 발주승인 탭
   - 권한에 따른 승인 대기 발주 요청 수 = 배지 숫자
   - middle_manager: 1차 승인 대기 건
   - final_approver: 최종 승인 대기 건
2. 입고대기 탭
   - 입고 대기 중인 항목 수 = 배지 숫자
   - 권한에 따라 볼 수 있는 항목만 포함

### 4. 일반 직원 테스트
**사용자**: roles에 특별 권한이 없거나 일반 직원 권한만 있는 사용자
**예상 결과**:
- 탭 바 없이 입고대기 위젯만 표시
- 배지 표시 없음 (탭이 없으므로)
- 본인이 요청한 입고대기 항목만 표시

**테스트 항목**:
1. 입고대기 화면
   - 본인 요청 건만 표시
   - 다른 사람의 요청은 표시되지 않음

### 5. 연차/출장 승인 권한자 테스트
**사용자**: roles에 manager 권한이 있는 사용자
**예상 결과**:
- 연차/출장 탭 포함 표시
- 연차/출장 탭의 배지 숫자 = 승인 대기 중인 연차/출장 신청 수

**테스트 항목**:
1. 연차/출장 탭
   - 해당 부서의 승인 대기 건 수 = 배지 숫자
   - admin: 모든 직원의 신청
   - manager: 해당 부서 직원의 신청만

## 배지 카운트 검증 방법

### 데이터 일치성 확인
1. 각 탭을 클릭하여 실제 표시되는 카드 개수 확인
2. 탭의 배지에 표시된 숫자와 비교
3. 숫자가 일치하는지 확인

### 실시간 업데이트 확인
1. 새로운 요청이 생성될 때 배지 숫자 증가 확인
2. 요청이 처리될 때 배지 숫자 감소 확인
3. 화면 새로고침 시 배지 숫자 유지 확인

### 캐시 동작 확인
1. 앱 시작 시 캐시된 배지 숫자 즉시 표시 확인
2. 데이터 로드 완료 후 실제 숫자로 업데이트 확인
3. 네트워크 오류 시 캐시된 숫자 유지 확인

## 예상 문제점 및 해결 확인

### 1. 권한별 필터링
- **문제**: 역할에 따라 다른 데이터가 표시되어야 함
- **확인**: 각 역할로 로그인하여 올바른 데이터만 표시되는지 확인

### 2. 배지 카운트 계산
- **문제**: 복잡한 조건에 따른 카운트 계산
- **확인**: PurchaseProvider의 카운트 계산 로직이 올바른지 확인

### 3. 탭 표시 조건
- **문제**: 역할에 따라 다른 탭이 표시되어야 함
- **확인**: 각 역할별로 올바른 탭만 표시되는지 확인

## 테스트 실행 방법

1. 각 역할의 테스트 계정으로 로그인
2. 승인 관리 화면 진입
3. 표시되는 탭과 배지 확인
4. 각 탭 클릭하여 실제 데이터와 비교
5. 새로운 요청 생성/처리하여 동적 업데이트 확인
